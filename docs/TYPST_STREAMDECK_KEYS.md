# TYPST_STREAMDECK_KEYS

Touches et actions prévues pour le fork Typst.

## Édition

- `Ctrl+S` : sauvegarder
- `Ctrl+Alt+R` : relancer le rendu Typst
- `Ctrl+Alt+K` : ouvrir le fichier courant dans Kate
- `Ctrl+Alt+O` : ouvrir le dernier PDF valide dans Okular
- `Ctrl+Alt+D` : ouvrir le dossier de rendu
- `Ctrl+Alt+E` : aller à l'erreur Typst signalée

## Mise en forme

- `Ctrl+B` : gras
- `Ctrl+I` : italique
- `Ctrl+K` : lien
- `Ctrl+Shift+K` : wikilink
- `Ctrl+\`` : code

## Navigation

- `Ctrl+F` : recherche
- `Ctrl+H` : remplacement
- `F3` : recherche suivante
- `Shift+F3` : recherche précédente

## Tableaux

- `;table` ou le menu contextuel : insertion d'un tableau Typst
- assistance intégrée pour parcourir les cellules au clavier
